# Marcus Rafael B. Tiongson — Portfolio

A visual portfolio that lets the work lead. Six distinct, browsable interface worlds present the same real project archive from different points of view: a Field Atlas, Screening Room, Arcade Marquee, Dada Contact Sheet, VU Meter Bridge, and a clean classic index.

The experiences share one project catalog and verified media, but each gets a complete, standalone visual language. This keeps the portfolio extensible: future work should be added once to the shared catalog and become available in every world.

## Development

This is a static site for GitHub Pages (`https://mbtiongson1.github.io`). No secrets or server runtime belong here. Local preview instructions and project-source/provenance notes will be added with the site foundation.

## Publishing safeguards

- Prefer public project links and carefully reviewed images over copying private source code.
- Synthetic or prototype data is labelled at the point of viewing.
- Do not publish connected or production systems, credentials, private operational reports, or unreviewed project files.
